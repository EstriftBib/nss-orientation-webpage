# NSS NIT Silchar — Orientation Poster Webpage

An interactive, responsive single-page web application displaying the 6-panel orientation poster for the NSS NIT Silchar UG 2026–2030 batch.

## Features

- **Responsive Design**: Optimized for seamless viewing on both mobile devices and desktop screens.
- **Infinite Loop Carousel**: Smooth infinite looping when navigating forward from the final panel back to the first, and vice versa.
- **Multi-Input Controls**:
  - Touch-swipe support for mobile devices.
  - On-screen navigation arrows for desktop.
  - Keyboard arrow key controls (`Left` / `Right`).
  - Clickable pagination indicators.

## Panel Order

1. **Panel 1 (`panel1.jpg`)**: Welcome & UG 2026–2030 Batch Announcement
2. **Panel 2 (`panel4.jpg`)**: About NSS, Motto & Major Activities
3. **Panel 3 (`panel6.jpg`)**: Benefits & Frequently Asked Questions
4. **Panel 4 (`panel5.jpg`)**: Event Photo Gallery
5. **Panel 5 (`panel3.jpg`)**: Orientation Schedule & Recruitment Process
6. **Panel 6 (`panel2.jpg`)**: Contact Information & Social Media Links

## Local Setup

1. Clone or download this repository.
2. Ensure all image files (`panel1.jpg` through `panel6.jpg`) are stored in the same directory as `index.html`.
3. Open `index.html` directly in any web browser.

## Deployment

This site is deployed live on Vercel.
